HTML导致浏览器崩溃的演示

警告： 此页面包含可能导致浏览器变慢、无响应甚至崩溃的代码示例。 请谨慎操作，并确保您已保存所有工作。

1. 无限循环的JavaScript

这段代码会创建一个无限循环，迅速消耗CPU资源。

while(true) { /* 无限循环 */ }

2. 内存泄漏

通过不断创建对象而不释放，消耗浏览器内存。

let data = [];
function addData() {
  data.push(new Array(1000000).join('x'));
}

3. 大量DOM元素

创建大量DOM元素可能导致浏览器变慢。

for(let i = 0; i < 100000; i++) {
  document.body.appendChild(document.createElement('div'));
}

已创建元素数量: 0

4. 递归函数导致栈溢出

深度递归可能导致调用栈溢出。

function recursive() {
  recursive();
}

5. 同步阻塞操作

执行长时间运行的同步操作会阻塞浏览器。

let start = Date.now();
while(Date.now() - start < 10000) { /* 阻塞10秒 */ }

如何防止浏览器崩溃

  • 避免无限循环和深度递归
  • 使用Web Workers处理CPU密集型任务
  • 合理管理内存，及时释放不需要的对象
  • 使用分页或虚拟滚动处理大量数据
  • 避免长时间运行的同步操作
